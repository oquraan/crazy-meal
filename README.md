# crazy-meal



### Overview  

>In this lab, you will build a web application for a chicken restaurant called Crazy Meal. It will allow you to add and track customer orders by entering details like: meal
name, meal price and image of the meal.

You will practice key programming skills including creating objects using constructor functions, manipulating the DOM to display dynamic data, handling form
submissions, and saving data using the browser's IocalStorage.

This project simulates a real-world restaurant order system in a simple and beginner-friendly way.
